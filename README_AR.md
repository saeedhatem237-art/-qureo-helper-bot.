# Qureo Helper Bot — نسخة تجريبية

بوت تيليجرام تعليمي يستقبل نص السؤال أو صورة واضحة، ثم يرسلها إلى خدمة ذكاء اصطناعي متوافقة مع واجهة OpenAI للحصول على شرح واقتراح حل.

## مهم قبل الاستخدام
- هذا **مش بوت جاهز شغال بمجرد فك الضغط**؛ يحتاج استضافة تعمل باستمرار، وتوكن تيليجرام، ومفتاح خدمة ذكاء اصطناعي.
- بعض خدمات الذكاء الاصطناعي مدفوعة أو لها حدود مجانية تتغير. لا أقدر أضمن أن التشغيل سيكون مجانيًا بالكامل.
- لا ترسل كلمة مرور QUREO أو بيانات حسابك إلى البوت.
- البوت لا يسجّل الدخول إلى QUREO ولا يضغط أزرار الإجابة أو الإرسال تلقائيًا.

## إعداد تيليجرام
1. افتح Telegram وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع الخطوات.
3. انسخ التوكن الذي يعطيه لك BotFather. **لا تشاركه مع أي شخص**.
4. اختر منصة استضافة تدعم تشغيل Python وبرامج تعمل باستمرار.
5. أضف متغير البيئة `TELEGRAM_BOT_TOKEN` بالتوكن.
6. أضف `AI_API_KEY` و`AI_BASE_URL` و`AI_MODEL` حسب خدمة الذكاء الاصطناعي التي اخترتها.
7. ثبّت المكتبات من `requirements.txt` وشغّل `python bot.py`.

## متغيرات البيئة
- `TELEGRAM_BOT_TOKEN`: مطلوب لتشغيل بوت تيليجرام.
- `AI_API_KEY`: مفتاح خدمة الذكاء الاصطناعي.
- `AI_BASE_URL`: عنوان API المتوافق مع OpenAI، الافتراضي OpenAI.
- `AI_MODEL`: اسم النموذج الذي تدعمه الخدمة.

## ملاحظات
- البوت يقبل النصوص والصور المرسلة كصور تيليجرام.
- لو لم تضبط مفتاح الذكاء الاصطناعي، سيشرح البوت أن الإعداد ناقص ولن يتمكن من حل الأسئلة.
- لا تضع المفاتيح داخل ملفات عامة أو ترسلها في المحادثات.
